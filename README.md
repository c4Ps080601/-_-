# 📖 续写批改站_面向高考生的英语续写批改软件

亲爱的同学，亲爱的老师及教育工作者，您好！作为2026年浙江高考英语143的一名考生，我曾被续写练习后的批改问题困扰许久：难找到老师、自己查不出错误、明明能用AI却用不好......于是，我开发了这一款续写批改软件，其内置的批改准则源于我长期以来的真实一线考场经验，紧密贴合高三同学的实际场景，同时做了交互优化，为还在一线奋战的各位提供一个相对方便可靠的解决办法。希望能够帮助到大家！

一款面向高考英语读后续写的桌面批改工具。上传题目和手写作文照片，核对识别出的文字稿，即可获得评分、亮点分析、错误订正和润色参考，也可以直接提交文字稿。

项目围绕实际续写训练中的需求开发：保留学生原稿，区分确定错误与表达建议，让评分和修改依据能够被检查、讨论和复核。

**🏷️ 版本 3.1.3　｜　🖥️ Windows x64　｜　🔑 用户自备 API Key**

## ✨ 功能

- 📷 **照片识别**：识别阅读原文、两段给定开头和学生续写，保留识别疑点，支持手动修改文字稿。
- 💾 **自动保存草稿**：识别完成后生成最近作文条目，批改时显示状态，便于切换页面后继续查看。
- 🎯 **25 分制批改**：提供整体评分及情节、语言、语法、衔接四维分析。
- 🔎 **分类反馈**：分别展示确定错误、待核实问题、表达提升建议和写作亮点。
- ✍️ **润色参考**：保留两段结构和给定开头，展示参考文本及修改变化。
- 👩‍🏫 **教师终评**：支持教师调整分数、补充评语。
- 📤 **结果导出**：支持 PDF 和完整长图，方便保存、分享和复习。
- 🎨 **桌面阅读**：左侧导航、浅色与深色主题、四档字号；学生续写与润色参考的给定段首句加粗。
- ⚙️ **自选模型**：图片识别和文字批改可分别配置服务商、模型及密钥。

## 🚀 开始使用

1. 安装并打开「续写批改站公开版」。当前安装包面向 Windows x64；发布到 GitHub 后，可从仓库的 Releases 页面获取。
2. 输入用户名进入软件。用户名用于本机区分作文记录，不是云端账号。
3. 按首次使用提示打开「设置」，填写自己的 API Key，并选择服务商和模型。
4. 在「提交作文」中上传题目与作文照片，点击识别；也可直接输入题目和续写文字。
5. **逐字核对文字稿**，尤其是拼写、标点、段首句和识别疑点，然后提交批改。
6. 提交后保持软件运行，可在左侧查看「批改中」状态，完成后查看或导出结果。

> [!TIP]
> 识别完成后，请先核对文字稿再批改。识别错误若未修正，可能被批改模型当作语言错误。图片识别所用模型必须支持视觉输入；文字连接测试成功不代表模型能识别照片。

公开版中，用户名「教师」可使用教师终评功能。这是本机功能入口，不是身份认证或权限隔离机制。本机不同用户名共享 API 设置。

图片识别与文字批改可以使用不同模型；如果一个模型同时支持文字和图片，也可以共用配置。模型 ID、可用区域及参数范围须以所用账户和接口为准。

DeepSeek Flash 的自动策略为**识别 Low、批改 High**。其他服务商按适配规则使用对应参数或服务商默认行为，详细说明见 [API 配置与适配](docs/API.md)。

设置中的「连接测试」由用户主动触发，发送固定短文本，可能产生少量费用。模型调用费用由用户自己的服务商账户承担。

> [!NOTE]
> 接口适配已通过模拟请求与响应测试，尚未使用真实账户逐家付费验收。自定义接口需要兼容所选协议，不能保证任意专有 API 都能直接使用。

## 📝 批改依据与使用边界

批改提示词结合高考读后续写评价框架与教师经验规则编写。它是辅助训练工具，不是官方阅卷系统，输出分数也不等同于真实考试成绩。

当前评分原则包括：

- **整体定档决定总分**，四维分析用于解释与校验评分依据。
- **确定错误参与扣分**；存疑问题和“可以写得更好”的建议不计入确定错误数。
- 同一位置、同一实际错误的重复条目合并，独立位置的问题分别记录。
- 情节合理或仅有轻微瑕疵且续写完整时，按经验规则保底 15 分。
- 独立确定错误达到 12 项时，最高 19 分；达到 14 项时，最高 17 分。
- 保留严格评分尺度：优秀作文通常约 22 分，23—25 分需要充分、具体的全文依据；22 分不是硬上限。

以上保底、封顶和严格尺度属于本项目采用的经验规则，不应当作所有地区、所有考试的官方规定。

批改阶段依据核对后的文字稿，不评价手写卷面的整洁度或字体美观度。同一稿件每次独立调用 AI，可能出现小幅分差；语言判断和情节评价仍需人工复核。润色文本供学习参考。

具体提示词及结果校验逻辑见 [rubric.js](rubric.js)。

## 🔒 数据与隐私

公开版不内置开发者 API Key，不通过开发者服务器中转模型请求。作文记录和设置保存在本机，默认数据目录为：

```text
%APPDATA%\essay-grader-public
```

- **密钥存储**：Windows 下使用 Electron `safeStorage` / DPAPI 加密保存；设置界面只显示配置状态，不回显已保存的密钥。
- **调用去向**：调用模型时，密钥会发送给用户选择的服务商进行认证；照片或文字稿也会发送给该服务商处理。
- **数据处理**：服务商如何保存、使用请求内容，取决于该服务商的规则和账户设置。
- **版本隔离**：公开版使用独立数据目录，不自动导入旧自用版的密钥、照片、作文或设置。
- **删除密钥**：清理作文数据会保留 API 设置；需要删除密钥时，在对应配置中勾选删除并保存。

远程接口仅允许 HTTPS；本地兼容接口可使用 localhost / 127.0.0.1 的 HTTP 地址。请使用可信接口，勿分享密钥或设置文件。本机加密无法保证被入侵的电脑安全，也无法阻止同一 Windows 用户权限下的恶意程序访问数据。

## 🛠️ 本地开发与构建

技术栈：Electron、Node.js、Express、原生 JavaScript / CSS。测试使用 `node:test` 和 Playwright。

在项目根目录安装依赖并启动：

```sh
npm ci
npm run dev
```

运行测试：

```sh
npm test
```

生成 Windows 安装包：

```sh
npm run dist
```

构建产物位于 `dist/`。首次安装依赖或构建时需要下载 Electron 和构建工具。Windows 构建会写入原图标和版本资源，缺少相关工具时会阻止构建。

密钥配置需在 Electron 中运行，以使用系统加密服务；单独运行 Node 后端不提供明文保存密钥的降级方式。当前交付和验证范围为 Windows x64，其他平台尚未完成发布验收。
